Architecture

End-to-End Event-Driven Data Flow

1. Raw S3 Ingestion Zone

Incoming POS CSV files land in raw/transactions/ with SSE-S3 encryption, Versioning, Public Access Block, and TLS-only bucket policy.

2. S3 Prefix Notification

Filtered strictly on raw/transactions/*.csv so writes to curated/ or quarantine/ never re-trigger Lambda.

3. Lambda Validation Engine

Validates headers, types, store/SKU patterns, duplicate IDs, and discount bounds; computes gross_amount and net_amount.

4. Curated & Quarantine Zones

Valid rows write to curated/transactions/transaction_date=YYYY-MM-DD/; bad rows write to quarantine/transactions/.

5. Glue Catalog & Athena

Glue table uses Partition Projection for zero-latency SQL queries in a cost-governed Athena workgroup (10 GB scan cap).

6. CloudWatch & SNS Alarms

Structured JSON logs feed metric filters for QuarantinedRowCount, SchemaValidationFailures, and Lambda invocation errors.
